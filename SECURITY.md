# Security policy

## Reporting a vulnerability

Please report security issues privately through GitHub's private vulnerability
reporting: open the **Security** tab of
[Eleven-Estudio/claude-pinboard](https://github.com/Eleven-Estudio/claude-pinboard/security)
and choose **Report a vulnerability**. Do not open a public issue for it.

You can expect a first answer within a week. Only the latest release is supported.
